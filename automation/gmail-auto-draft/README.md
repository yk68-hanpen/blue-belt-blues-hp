# 問い合わせ自動下書き作成 (Google Apps Script)

Formspreeの問い合わせ通知メールを検知し、OpenAI APIで返信文を生成して
Gmailの下書きに保存するスクリプト。送信は行わず、必ず人が内容を確認してから送る。

## セットアップ手順

1. **問い合わせ通知を受け取っているGmailアカウント**で https://script.google.com/ を開き、
   「新しいプロジェクト」を作成する。
2. エディタに `Code.gs` の内容をそのまま貼り付けて保存する。
3. 左メニューの「プロジェクトの設定」→「スクリプト プロパティ」で以下を追加する。
   - `OPENAI_API_KEY`: https://platform.openai.com/api-keys で発行したAPIキー
     (ChatGPTの契約とは別に、API利用分の従量課金が発生する)
   - 以下は任意（未設定ならデフォルト値が使われる）
     - `OPENAI_MODEL` (デフォルト: `gpt-4o-mini`)
     - `LABEL_NAME` (デフォルト: `bbb-auto-drafted`)
     - `REVIEW_LABEL_NAME` (デフォルト: `bbb-needs-review`)
     - `MAX_THREADS` (デフォルト: `10`、1回の実行で処理する最大スレッド数)
4. エディタ上部の関数選択で `debugDumpLatestFormspreeEmail` を選び、一度実行する。
   - 初回はGmailへのアクセス許可を求められるので許可する。
   - 実行ログ（表示 → ログ）に実際のFormspree通知メールの本文が出力されるので、
     `parseFormspreeFields_` が想定通りに `name / email / experience / belt / message` を
     抜き出せそうか確認する。形式が違う場合はこの関数の正規表現を調整する
     （`sample-email.txt` に実メールの見本を置いてあるので、それも参考にする）。
5. 関数選択で `createTrigger` を選んで一度だけ実行する。
   - これで `processInquiries` が1時間おきに自動実行されるようになる。
   - トリガーの確認・削除は左メニューの「トリガー」から行える。
6. 実際にサイトのお問い合わせフォームからテスト送信し、最大1時間待ってから
   Gmailの「下書き」フォルダを確認する（急ぎで確認したい場合はエディタから
   `processInquiries` を手動実行してもよい）。
   - 正常に処理されたスレッドには `bbb-auto-drafted` ラベルが付く。
   - 必須項目が読み取れなかった場合は `bbb-needs-review` ラベルが付き、
     下書きは作成されない（手動対応が必要）。

## 動作の流れ

1. `processInquiries` が1時間おきに実行される。
2. Formspreeからの未読メールのうち、まだラベルが付いていないものを検索する。
3. メール本文から問い合わせ内容（氏名・メール・経験・帯・メッセージ）を抽出する。
4. OpenAI APIに、サイトに書かれている事実（インストラクター不在、日程は都度調整、
   流山市内の施設、1回300〜500円、見学・体験は無料）を踏まえた返信文を生成させる。
5. 問い合わせ者のメールアドレス宛てに、件名・本文を入れたGmail下書きを作成する。
6. 元の通知メールを既読にし、処理済みラベルを付ける（二重処理防止）。

## 注意点

- 下書きは**自動送信されない**。内容を確認し、必要なら手直ししてから送信すること。
- 次回の練習日時・場所はAIが把握できないため、本文中に
  `日時：【次回の練習日時を記入】` / `場所：【流山市北部柔道場 または キッコーマンアリーナ を記入】`
  というプレースホルダーがそのまま残る。**送信前に必ず手で埋めること。**
- 文面のスタイル（宛名・書き出し・定型文・結び）は過去の実際の返信メールを参考に
  システムプロンプトへ反映済み。実メール自体は個人名を含むため、このリポジトリ
  （GitHub上でpublic設定）には一切保存していない。
- OpenAI APIの出力は事実を断定しないよう指示しているが、送信前の目視確認は必須。
- `OPENAI_API_KEY` はスクリプト プロパティにのみ保存され、このリポジトリや
  公開ページには一切含まれない。
- Formspreeのメールテンプレートが変わると `parseFormspreeFields_` の抽出に失敗する
  ことがある。その場合は `bbb-needs-review` ラベルが付くだけで下書きは作られないため、
  安全側に倒れる設計になっている。
- 問い合わせ頻度が低いため実行間隔は1時間にしてある。頻度を上げたい場合は
  `createTrigger` の `everyHours(1)` を `everyMinutes(5/10/15/30)` などに変更して
  トリガーを作り直す（Apps Scriptの分間隔は5/10/15/30のみ指定可能）。
